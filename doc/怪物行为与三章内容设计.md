## 行为框架

层次为：行为类别 → 具体行为 → 本回合行动。

| 类别 | 值 | 用途 | 示例 |
|---|---:|---|---|
| 攻击 | 0 | 直接造成伤害，可附带状态 | 单次、多段、伤害附带流血、吸血 |
| 防御 | 1 | 护盾和防御架势 | 获得护盾、单次格挡、有限反伤 |
| 技能 | 2 | 状态、恢复与特殊准备 | 治疗、力量、虚弱、蓄力 |

每只怪物拥有1～3种类别，每类可以有多个具体行为。每次只选择并执行一个行为ID，该行为内的多个效果按步骤执行。例如鸡的撕裂啄击先造成3伤害，再施加流血，仍是一次攻击行为。

行为库直接写在怪物表中，例如 `1;2;3`。类别由引用行为汇总，不在怪物表重复填写。

| 行动模式 | 值 | 执行规则 |
|---|---:|---|
| 固定 | 0 | 从左至右，末尾后回到开头；`1;1;2;3`允许重复 |
| 随机 | 1 | 每回合选一个，允许连续重复；空权重等概率 |

权重只用于随机模式，逐项对应行为列表。`1;2;3`配权重`3;1;2`，概率分别为50%、16.7%、33.3%。固定模式的权重必须留空。

如果随机列表重复填写相同ID，按多个位置参与抽取，相当于增加该行为总权重。为便于维护，随机模式建议每个ID只列一次，概率通过权重表达。

所有行为预先展示意图。第一章不用伤害浮动。怪物受力量/虚弱影响时，按每段伤害乘倍率后四舍五入，意图与实际结算一致。

## 结算与状态边界

### 护盾与架势

护盾继续沿用现有规则：自身回合开始清除上轮护盾。怪物防御后获得的护盾可用于抵挡下一玩家回合的攻击，到怪物下一次行动开始清除。

单次格挡先减伤，再由护盾吸收，最后扣生命；一次正数攻击就消耗全部格挡次数，即使攻击小于减伤值。零伤害不消耗。流血不消耗单次格挡。

反伤架势在每段有效受伤后立即结算，可被玩家护盾吸收。第一章有效受伤指实际扣除护盾或生命，完全被单次格挡阻止的攻击不触发。次数上限在架势创建时给定；未用完次数到怪物下一次行动开始失效。致命一击仍可反伤，双方同时死亡判玩家失败。

### 流血

玩家回合结束时结算，先执行回合结束战利品（例如回转鼓组加盾），再结算流血，随后推进玩家力量/虚弱并执行怪物行动。

流血可被护盾吸收。重复施加分别取较高伤害与较长剩余时间，不累计伤害或延长时间之和。施加当下不跳血，到受影响角色下次回合结束首次触发。流血致死后直接失败，不执行怪物行动。

### 蓄力

技能回合只准备蓄力，不同时重炮。下个玩家回合提供打断窗口，下一怪物回合执行重击。

首版只支持固定循环，且蓄力后必须紧邻带取消替代行为ID的攻击。达标立即更新当前意图，改为较弱攻击；仍只执行一次行为，并推进原列表一次。

有效伤害 = 实际消耗的护盾 + 实际扣除的生命；不包含单次格挡量及溢出伤害。有效命中 = 一次造成至少1点有效伤害的事件。普通卡、多段、主动技、人字拖等追加伤害均参与；延迟飞球必须到真实命中时统计，出牌时不统计。

重击或替代攻击完成后清空蓄力。重新建局清空流血、格挡、反伤和蓄力，不写回共享资源。

### 现有状态

吸血仅按玩家实际生命损失治疗，不计算护盾吸收量。治疗不超过最大生命。

力量、虚弱沿用现有伤害倍率状态：同类延长回合，不叠乘；异类相互替换。新表中的自身力量持续时间指技能之后的完整自身回合数。

### 卡牌和战利品的用途

- 鸡：手套挡流血，嗜血球、佳得乐补续航；鼓手隔音屏减轻首回合损耗。

- 大象：鼓槌预热、助跑、大鼓槌、盾牌冲撞、城门爆破、能量射门用于18点伤害窗口；蓄能徽章与乐谱可以在防御/蓄力前准备。

## 游戏内容与奖励规划

总计10小怪、5精英、3Boss。每章建议4～5普通战斗、1可选精英、1Boss，中间穿插商店、休息、事件。此处是路线规划建议，本次未修改地图节点数量或生成规则。

普通战斗补卡与组合；精英提供普通战利品；Boss沿用Boss奖励。现有启用Boss战利品只有葡萄牙7号和阿根廷10号，后续需补充多段、护盾、节奏方向Boss战利品，具体效果另行设计。

不设计某流派永久无效或删除战利品的敌人。暂时限制必须公开、短暂、可准备。自伤、低生命、高频出牌构筑通过意图决定何时冒险。

## CSV契约

三张CSV均在`tables`，UTF-8、三行表头、Godot importer为`keep`。第一行中文说明，第二行字段名，第三行类型。CSV列使用标准引号转义，行为列表单元格内部使用分号。

### monsters.csv

| 字段 | 类型 | 范围与用途 |
|---|---|---|
| id | uint16 | 新设计6001～6099；正式运行时查找键 |
| display_name | string | 非空显示名称 |
| tier | uint8 | 0小怪、1精英、2Boss |
| chapter | uint8 | 1～3 |
| max_health | uint16 | 1～9999 |
| action_mode | uint8 | 0固定、1随机 |
| action_ids | uint16_list | 非空、分号分隔、允许重复；1～65535 |
| action_weights | uint16_list | 固定留空；随机留空等概率，否则逐项对应正整数 |
| enabled | uint8 | 0禁用、1启用；禁用仍保留ID与目录记录 |
| source_file | string | 安全enemy_资源名，不含路径或扩展名；不能覆盖旧资源白名单 |

### monster_actions.csv

| 字段 | 类型 | 范围与用途 |
|---|---|---|
| id | uint16 | 唯一行为ID，1～65535 |

| interrupted_action_id | uint16 | 0无；重击被打断后引用的攻击行为ID，不能自引用或形成链 |

### monster_action_effects.csv

| 字段 | 类型 | 范围与用途 |
|---|---|---|
| id | uint16 | 唯一效果行ID，1～65535 |
| action_id | uint16 | 关联行为ID |
| step | uint8 | 每个行为从1连续递增 |
| effect_type | uint8 | 0伤害、1护盾、2治疗、3虚弱、4力量、5吸血、6流血、7格挡、8反伤、9蓄力 |
| target | uint8 | 0玩家、1怪物自身 |
| amount | uint16 | 0～999；伤害、护盾、治疗、流血、格挡、反伤的数值；蓄力填0 |
| hits | uint8 | 1～20；伤害段数或反伤次数；其余填1 |

怪物、行为、效果各自ID不可重复；三表首列按升序。固定列表允许同一个行为重复出现，但行为主表只定义一次。章节池必须有启用的小怪、精英和Boss。

力量、虚弱、蓄力的amount必须填0；非持续状态turns必须填0；非伤害/吸血/反伤的hits必须填1；非力量/虚弱的倍率必须填100。无效或被忽略的参数也会被导入器拒绝，避免策划填写后误以为已经生效。
