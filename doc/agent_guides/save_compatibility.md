# 存档与正式 ID 兼容规范

## 稳定身份

- CSV 第一列数字 `id` 是正式运行时唯一查找键；同类数据使用约定号段并永久唯一。
- 已发布或进入存档的数据 ID 不得复用。资源下架时保留原 ID，通过禁用标记退出奖励池。
- 英文 ID 只允许用于资源关联、配表内部关联或旧存档迁移，不得继续用于运行时查找、持有排重或特殊逻辑判断。
- 业务代码引用特殊战利品时使用带语义名称的数字常量，禁止散落裸数字。

## 迁移与容错

- 旧存档迁移映射必须保留；无法映射的旧值应安全忽略并记录诊断。
- 改变存档格式、本局状态或正式 ID 契约前，先确认既有格式、迁移入口、重复值处理、默认值和失败后的部分写入风险。
- 迁移不得复用已发布 ID，也不得以静默类型转换掩盖无效值。

## 验证矩阵

- 覆盖新格式保存与读取往返。
- 覆盖旧格式迁移、重复旧值、无法映射值和缺失字段。
- 涉及奖励池时，覆盖数字 ID 查找、持有排重、禁用项过滤和无效 ID。
- 失败路径必须确认不会破坏原存档；若存在写入风险，应使用可恢复副本验证并报告恢复方法。
