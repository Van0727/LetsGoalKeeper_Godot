# 子代理任务契约

主代理委派任务前必须填写以下内容，并确认不同写入任务的文件范围不重叠。子代理不是独立授权主体，仍受根 `AGENTS.md`、用户批准范围和命中的专项文档约束。

```markdown
# 子任务

## 目标

一句话说明需要得到的结果。

## 背景

只提供完成本任务必需的上下文，不复制整个对话。

## 允许读取

- 相关代码、文档和测试。

## 允许修改

- 明确列出目录或文件；只读任务写“无”。

## 禁止修改

- 明确列出高风险范围以及由其他代理负责的文件。
- 默认禁止 Git 提交、推送、重置、清理和切换分支。

## 必须读取的专项文档

- 没有则写“无”。

## 必须使用的 Skill

- 没有则写“无”。

## 完成条件

- 列出可验证的验收标准。

## 验证命令

- 列出允许执行的测试或只读检查。

## 交付格式

- 结论。
- 修改文件。
- 测试结果。
- 风险和未验证项。
```

## 文件所有权规则

- 同一时间只能有一个代理写入某个文件；多个代理可以只读检查同一文件。
- 子代理发现必须扩大写入范围时立即暂停并报告，不得自行扩大。
- 多个任务需要修改同一场景、CSV、测试或脚本时必须串行执行。
- 主代理负责最终集成、统一验证和 Git 决策。
